Development Retrospective

  • New Features: Implemented an AI-powered 'Ask the Barista' chat system for personalized drink recommendations and integrated favorite lists for users. Developed a fast search and category filtering system, added support for Dark/Light mode, and enabled profile customization including avatar changes and address management. Incorporated real-time order tracking using WorkManager with local notifications and a celebratory confetti effect for successful checkouts.
  • Techniques Applied: Utilized Jetpack Compose and Material 3 for a fully declarative and theme-aware UI. Employed Room Persistence Library for local caching of the menu, orders, and favorites, and Preferences DataStore for user settings and reward states. Implemented a robust MVVM architecture with StateFlow and the Repository pattern to ensure data consistency across the application.
  • Implementation Experience: The primary challenge was maintaining arithmetical consistency between Room-based order records and DataStore-based rewards, which was solved by centralizing logic in the repository layer. Debugging complex UI states occasionally required resetting to the latest stable commit to isolate issues. Learning to orchestrate WorkManager and local notifications provided valuable insights into building production-ready Android background services.
