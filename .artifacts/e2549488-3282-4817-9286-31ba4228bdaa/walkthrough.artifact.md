# Report Layout Beautification

I have refined the visual layout of your `MidtermReport.html` to ensure it looks professional and balanced when converted to PDF, without changing your content or established branding.

## Changes Made

### 1. Document Rhythm & Spacing
- **Balanced Header**: Adjusted the vertical spacing between the logos, title, and subtitle to create a more elegant document entry.
- **Student Info Area**: Re-styled the student information into a balanced, centered block with subtle borders.
- **Section Headers**: Standardized the spacing above and below section titles to improve the overall "vertical rhythm" of the report.

### 2. Table Refinement
- **Vertical Alignment**: Set all table cells to `vertical-align: middle` so that text and screenshots sit perfectly level with each other.
- **Score Badges**: Standardized the padding and border-radius of the scoring indicators for a cleaner, modern look.
- **Column Scaling**: Fine-tuned column widths (40% for requirements, 30% for images, 15% for scores) to ensure no content feels cramped in PDF.

### 3. Typography & Legibility
- **Text Justification**: Applied `text-align: justify` to the retrospective paragraphs to give them a formal, formal document appearance.
- **Font Consistency**: Maintained your Artisan Brew brand fonts (Poppins/Inter) while adjusting weights and sizes for maximum clarity in print.

### 4. PDF Optimization
- **Page Break Logic**: Added `break-inside: avoid` to table rows and retrospective blocks. This prevents a requirement or a feature description from being split awkwardly across two pages in your PDF.
- **Balanced Screenshots**: Added a subtle border to the app screenshots to make them stand out cleanly against the white page.

## Final Review
You can now open the HTML file and use **Print > Save as PDF**. The layout is now perfectly balanced and ready for submission while keeping all your content exactly as it was.
